# Field Manual — What Surrounds a Window

A measured manual of Claude Code's context machinery: what loads into a
window, from where, in what order — and what each mechanism actually does,
established by experiment rather than vendor documentation.

Written by **Serge Osaulenko** (Selenko) in September 2026, from measurements
taken on his own production Claude Code environment, and graded across 21
revisions. This is the public edition: examples are genericized, and every
behavior described was observed on that live system.

**Read it live:** https://sergeselenko.github.io/field-manual/
